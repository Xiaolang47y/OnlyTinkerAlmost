# OnlyTinkerAlmost
A mod for 1.20.1 Forge that disables non-Tinkers' Construct 3 tools and equipment.

#### Features
* Tools from vanilla and other mods will be unable to break blocks, weapons will be unusable, armor/elytra will be immediately unequipped when worn, and tools such as flint and steel, shears, and shields will be unusable.
* Restricted items can still be used for crafting.
* Items are exempt from being disabled in Creative mode, and this can be turned off in the config file.
* Any item can be allowed by mod namespace or item ID in the config file, with wildcard support.

The config file is located at `config/onlytinkeralmost-common.toml`.
